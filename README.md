
# MovieByte

MovieByte is a clean and simple movie, anime, and series download website built using HTML, CSS, and JavaScript.  
It features a responsive design, a dynamic carousel, trailer previews, and a user authentication interface.

---

## Features

- Movie, Anime, and Series download pages  
- Carousel slider with posters and descriptions  
- Trailer preview inside each movie card  
- Login and Sign Up modal system  
- Search bar for quick access  
- Responsive and clean UI  
- Simple and fast navigation  

---

## Technologies Used

- HTML  
- CSS  
- JavaScript

## How It Works

- The homepage displays a carousel of featured movies.  
- Each movie includes details, a trailer preview, and a download button.  
- Users can log in or sign up using the modal forms.  
- JavaScript handles carousel transitions and trailer toggling.
